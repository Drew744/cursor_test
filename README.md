# 🧪 Автоматизированное тестирование с Playwright

Этот проект содержит автоматизированные тесты для проверки доступности и функциональности сайта onliner.by.

## 🚀 Возможности

- ✅ **Автоматические тесты** доступности сайта
- 🔄 **Периодический запуск** по расписанию
- 📊 **Детальные отчеты** о результатах тестирования
- 🎯 **Мониторинг критических путей** пользователя
- 🔔 **Уведомления** о результатах тестов

## 📅 Расписание автоматических тестов

### Основные тесты (playwright.yml)
- **Ежедневно** в 9:00 UTC (12:00 по Москве)
- **Каждые 6 часов** (00:00, 06:00, 12:00, 18:00 UTC)
- **Каждый понедельник** в 8:00 UTC

### Мониторинг доступности (availability-monitoring.yml)
- **Каждые 2 часа** - базовая проверка доступности
- **Каждые 6 часов** - полная проверка критических путей

## 🛠️ Настройка автоматизации

### 1. GitHub Actions уже настроены

Проект содержит готовые workflow файлы:
- `.github/workflows/playwright.yml` - основные тесты
- `.github/workflows/availability-monitoring.yml` - мониторинг доступности

### 2. Ручной запуск тестов

Вы можете запустить тесты вручную через GitHub UI:

1. Перейдите в **Actions** → **Playwright Tests**
2. Нажмите **Run workflow**
3. Выберите параметры:
   - **test_type**: all, smoke, onliner
   - **browser**: chromium, firefox, webkit

### 3. Настройка уведомлений

Для получения уведомлений о результатах тестов:

1. В настройках репозитория включите **Actions** уведомления
2. Настройте email или Slack уведомления
3. Добавьте webhook для интеграции с внешними системами

## 🔧 Локальный запуск тестов

### Установка зависимостей
```bash
npm install
```

### Запуск всех тестов
```bash
npx playwright test
```

### Запуск конкретного теста
```bash
npx playwright test tests/Onliner.spec.js --grep "навигация по каталогу"
```

### Запуск с видимым браузером
```bash
npx playwright test --headed
```

### Запуск в режиме отладки
```bash
npx playwright test --debug
```

## 📊 Просмотр результатов

### GitHub Actions
- Результаты автоматических тестов: **Actions** → **Playwright Tests**
- Отчеты о доступности: **Actions** → **Site Availability Monitoring**

### Локальные отчеты
```bash
npx playwright show-report
```

## ⚙️ Настройка расписания

Для изменения расписания автоматических тестов отредактируйте файлы:

### Основные тесты (playwright.yml)
```yaml
schedule:
  # Каждый день в 9:00 UTC
  - cron: '0 9 * * *'
  # Каждые 6 часов
  - cron: '0 */6 * * *'
```

### Мониторинг доступности (availability-monitoring.yml)
```yaml
schedule:
  # Каждые 2 часа
  - cron: '0 */2 * * *'
```

## 🚨 Мониторинг и алерты

### Успешные тесты
- ✅ Зеленый статус в GitHub Actions
- 📊 Отчеты сохраняются как артефакты
- 🔔 Уведомления о успешном выполнении

### Неудачные тесты
- ❌ Красный статус в GitHub Actions
- 📧 Email уведомления (если настроены)
- 💬 Комментарии к коммитам с деталями ошибок

## 🔄 Интеграция с CI/CD

Тесты автоматически запускаются:
- При **push** в main/master ветку
- При создании **pull request**
- По **расписанию** (cron)
- При **ручном запуске**

## 📈 Метрики и аналитика

### GitHub Insights
- Время выполнения тестов
- Частота успешных/неудачных запусков
- Тренды производительности

### Playwright Report
- Детальные отчеты о тестах
- Скриншоты при ошибках
- Видео выполнения тестов

## 🆘 Устранение неполадок

### Тесты не запускаются
1. Проверьте настройки GitHub Actions
2. Убедитесь, что workflow файлы в `.github/workflows/`
3. Проверьте права доступа к репозиторию

### Ошибки в тестах
1. Просмотрите логи в GitHub Actions
2. Скачайте артефакты с результатами
3. Запустите тесты локально для отладки

### Изменение расписания
1. Отредактируйте cron выражения в workflow файлах
2. Зафиксируйте изменения в main ветке
3. GitHub автоматически обновит расписание
