# 🧪 Автоматизированное тестирование с Playwright

Этот проект содержит автоматизированные тесты для проверки доступности и функциональности сайта onliner.by.

## 🚀 Возможности

- ✅ **Автоматические тесты** доступности сайта
- 🔄 **Периодический запуск** по расписанию
- 📊 **Детальные отчеты** о результатах тестирования
- 🎯 **Мониторинг критических путей** пользователя
- 🔔 **Уведомления** о результатах тестов

## 📅 Расписание автоматических тестов

### Основной workflow (`playwright.yml`)
- **Ежедневно** в 9:00 UTC (12:00 по Москве)
- **Каждые 6 часов** (0:00, 6:00, 12:00, 18:00 UTC)
- **Каждый понедельник** в 8:00 UTC

### Мониторинг доступности (`availability-monitoring.yml`)
- **Каждые 2 часа** для базовых проверок
- **Каждые 6 часов** для критических путей

## 🛠️ Настройка

1. **Клонируйте репозиторий**
2. **Установите зависимости**: `npm install`
3. **Установите браузеры**: `npx playwright install`

## 🎮 Ручной запуск тестов

### Через GitHub UI
1. Перейдите в **Actions** → **Playwright Tests**
2. Нажмите **Run workflow**
3. Выберите тип тестов:
   - `all` - все тесты
   - `smoke` - только smoke тесты
   - `onliner` - только тесты onliner.by
4. Выберите браузер (chromium, firefox, webkit)

### Локально
```bash
# Все тесты
npx playwright test

# Только тесты onliner.by
npx playwright test --grep "onliner"

# С видимым браузером
npx playwright test --headed

# В режиме отладки
npx playwright test --debug
```

## 📁 Структура тестов

- `tests/onliner-availability.spec.js` - тесты доступности onliner.by
- `tests/BuyWashingMachine.spec.js` - тест покупки стиральной машины

## 🔍 Просмотр отчетов

После выполнения тестов:
1. **Локально**: `npx playwright show-report`
2. **GitHub Actions**: скачайте артефакт `playwright-report`

## ⚙️ Конфигурация cron

- `0 9 * * *` - каждый день в 9:00 UTC
- `0 */6 * * *` - каждые 6 часов
- `0 8 * * 1` - каждый понедельник в 8:00 UTC
- `0 */2 * * *` - каждые 2 часа

## 📊 Мониторинг и алерты

- Автоматические уведомления о результатах тестов
- Отчеты о доступности сайта
- Мониторинг критических пользовательских путей

## 🚨 Устранение неполадок

### Тесты не запускаются
1. Проверьте статус GitHub Actions
2. Убедитесь, что workflow файлы корректны
3. Проверьте логи выполнения

### Тесты падают
1. Запустите тесты локально с `--headed`
2. Проверьте селекторы элементов
3. Убедитесь в доступности сайта
